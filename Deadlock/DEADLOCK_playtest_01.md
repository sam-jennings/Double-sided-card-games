# DEADLOCK — Playtest 01

*First physical playtest · reported by the designer, 23 November 2026*

## Setup

| | |
|---|---|
| Version | Rulebook draft v0.1 |
| Players | 2 (the designer and Noah) |
| Format | One sitting at a table ("The Sitting"), not the multi-day shelf format |
| Deck | Full 36, 6 × 6 field |
| Length | About 10 minutes |
| Seat rule used | None — no South bonus (the concept's original rules) |
| Result / scores | North (first player) won **13–11**. With the draft's South +1 it would still have been a North win, 13–12. |

## What the table said

- **Very positive from both players.** The game played well, with the right balance of strategy and simplicity.
- **It is a one-sitting game.** It took about 10 minutes, and the strategy is not so deep that a player spends minutes planning several moves ahead. Both players felt it wants to be played straight through.
- **It does not meet its original brief.** The concept was written as a game played one move per passing over days. The table found a strong short game instead, and the designer's verdict is to keep it in the collection as a proven game.

## Hypotheses

| Recorded question | Result |
|---|---|
| Is the game fun and teachable at the table? | **Confirmed** — strong positive reaction from both players. |
| Does the shelf / over-days format work? | **Refuted as the main identity** — the game's depth and length suit one sitting. The shelf format itself was not tried, so its handling risks (knocked cards, repairs, turn checks over days) remain untested. |
| One-sitting length (draft guessed ~20–30 min) | **Shorter than predicted** — about 10 minutes. |
| Seat balance (sim: North wins ~70% of careful games without a fix) | **Open, consistent with the sim** — played with no bonus; North won 13–11, close to the sim's typical careful score (about 12–11.5). One game cannot measure a seat edge. |
| Crowns decide many ties; line values mostly 2–3 | **Open** — not reported. |

## Bugs found

None reported at the table. No handling problems were noted.

## Rule-change candidates

- **Make the one-sitting game the main format** and present the shelf format as a variant (or drop it). Tied to the observation that the game plays in ~10 minutes and suits a single sitting.
- **Correct the stated length** to about 10 minutes.

## Verdict

**Iterate → Proven** (designer's call). The game works and the table wants it in the collection.

**Applied after this session (23 November 2026):** renamed VIGIL → DEADLOCK; rulebook v1.0 makes one sitting the main format, a two-game match with seats swapped the default, and South's point / South's ties the single-game options. The shelf format is now an untested variant.

The original "game played over days" brief is not met by DEADLOCK. If that format is still wanted, it needs a different design with deeper, slower decisions.
