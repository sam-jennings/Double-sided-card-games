## 0. Ground-truth corrections first

The brief said "complete and simulation-tuned: TRIGON, TURNCOAT" — but the repo has moved past that framing, and the plan must follow the table evidence, not the sim evidence:

- **The promoted collection today is TWELVE TRIALS, CROSSROADS, THE ORRERY** — the three games humans have played to an "iterate" verdict. All three carry open handling questions.
- **TRIGON's first table test did not go well** — not on mechanics, but on handling (undefined grid, crushing reference overhead). It is explicitly "not yet promotable." It remains the *depth* flagship candidate, but it is currently the collection's biggest teach-cost risk, not its proven star.
- **TURNCOAT has never been played by humans.** 22k sims ≠ Stage 3.
- **BLIGHT was the standout table test** — a first-time player read the rules unaided, called them clear, and a designed depth-line (slough-as-weapon) fired at the table. It is the strongest promotion candidate in the repo.
- **CROSSROADS is "iterate, on notice"** — the pass-to-win line is a potentially structural bug, twice-flagged end-trigger unfairness, and the flip economy (the game's whole point) is still untested.
- **JANUS is blocked** at deck-physics level (F7: no concealable draw deck exists). SLEEPER depends on the same physics being trustworthy at the table.

Implication: the flagship question is not "TRIGON + TURNCOAT, polish them" — it's a live selection problem, answered in §3.

## 1. Gap analysis: what must be true of the *collection* before any single game is pitch-ready

The product is unusual: the deck is the component, and the games are content. That inverts the normal gap analysis — several collection-level things are prerequisites for *any* single game's pitch, because every demo, blind test, and publisher meeting touches the shared deck.

### Must be true (blocking)

**G1 — The deck's physical story must be solved and written down.** The playtest findings show the deck itself, not any game, is where sessions break: no sortable hand axis (F1), the deal leaks a face of every card (F3), no concealable draw stack exists (F7/F10), draw and dead piles are indistinguishable (F9), orientation-as-state dies when cards move (F6/F12). A blind tester hits F1 and F9 in their first ten minutes with *any* game. DECK_CONVENTIONS.md is the right instrument; it must graduate from "proposed canon + open tensions" to a settled, one-page **Deck Handbook** that ships inside every rulebook. Open tension T1 (opaque container vs bag vs no-draw) is a *product decision* — it may add a component — and must be closed before component lists freeze.

**G2 — The symbol set must become a real visual identity.** F4 proved the deepest teaching risk: experienced card players assume suit and rank are independent axes, and on this deck sign *is* rank. Letter+number prototypes make that a convention; the shipping deck must make it a visual truth (icon + colour + numeral all reinforcing one identity, colourblind-safe across nine symbols, legible in a fan and at arm's length across a grid). This is the single best use of the budget (§5c) — the symbols are the product's face in every game, every photo, every pitch.

**G3 — A curated Core Set must be declared.** A pitch for "a deck and sixteen games in various states" is a pitch for nothing. Declare a **Core Set of 5–6 games** spanning the collection's range (party opener / trick-taking / tactical / solo / 2P duel), all at Stage 6+ of your framework. Everything else is officially *pipeline* — invisible to the outside world, available later as PNP extras, expansions, or stretch goals. The collection gate you already run (table-tested, iterate verdict, distinctness) is the selection mechanism; §3 proposes the slate.

**G4 — One flagship at Stage 7 (blind-validated), two or three supporters at Stage 6.** Not all Core Set games need blind testing before a pitch — but the flagship must survive rules-only play by strangers, because "reads the rulebook unaided" is exactly what a publisher's evaluation team does.

**G5 — A frozen component list.** Currently beautiful: 36 cards + "any small objects" counter kit + one T1 resolution (bag/cover). Freeze it. Every new design between now and pitch inherits it.

**G6 — The one-line positioning.** Exists in embryo in the market survey: *every pairing exists exactly once; the same card is two things depending on which face is up; no card backs.* Needs the consumer-language version (§6).

### Genuinely optional (do not block on these)

Final illustration beyond the symbol/icon system (publishers re-art anyway; anti-drift rule 2). Polishing all sixteen games — the pipeline's depth is a *pitch asset* as a sentence ("13 more designs in development"), not as thirteen more rulebooks. JANUS and SLEEPER — both hostage to unresolved deck physics; park them outside the Core Set without guilt. Translation-*readiness* is cheap and worth doing (short sentences, icon-forward, glossary — §5b); actual translation is the publisher's job. A patent — the survey found white space around US 4,588,193, but a filing costs more than your whole budget and card-game patents are near-unenforceable; a dated public record (BGG WIP posts, PNP releases) is the pragmatic prior-art stake. Fancy packaging, video trailers, a marketing site.

## 2. Product shape recommendation

Product-vision.md holds "what shape is this product?" open. Recommendation: **a small-box card game system — one 36-card deck, a Deck Handbook, and 5–6 games in one rules booklet — with a single flagship game leading all communication.**

Why: "one deck, many games" systems (The Decktet, Pairs, Palm Island's stated heirs) historically stall when marketed *as systems* — buyers need one game to want. Lead with the flagship; the system is the hook that makes it unlike every other card game, not the product name on the shelf. This shape also keeps both paths open: a publisher can buy the flagship with the system as upside; a Kickstarter can sell the system with the flagship as the demo.

A second, parallel shape falls out for free: **a 6-symbol subset is 15 cards** — inside Button Shy's 18-card wallet format. Any Core Set game playable at 6 symbols is a standalone wallet-game pitch/contest entry that markets the master system at zero cost.

## 3. Flagship sequencing

### Flagship 1 — BLIGHT (push to pitch-ready now)

The evidence: cleanest first table test in the repo, rules already survive unaided reading, a familiar genre (trick-taking) with a hook that is *impossible without this deck* — the back of the card is the poison, and the rot pile remembers everything so nobody has to. Steepest measured skill gap in the trick-taking pair (2.02×). Familiar-genre-plus-twist is also the easiest pitch sentence in the collection. Its open questions (4P/6P hand-handling, match-length luck washout) are answerable in two sessions. GLEAN rides along cheaply as the same engine inverted — a "one deck, two trick-takers" story — but not for free: its first test (June 2026) refuted Plunder scoring (double-face pip sums were tedious arithmetic), and the intended majority scoring is still untested at the table.

### Flagship 2 — TRIGON (conditional, decision gate ~day 45)

The overview calls it the flagship candidate and it's the collection's depth statement — but it must *earn* the slot by passing a re-test with the centre-first grid fix and a proper player-aid, at 2P. If the second test still bogs down in reference overhead, **demote it to "expansion-tier depth game" without guilt** and let the Core Set lead lighter. Do not let sunk simulation cost (~23k games) decide this; the table decides.

### The opener — WILDFIRE (supporting, but strategically vital)

Ten minutes, no abilities, teaches the deck's flipping feel. Every demo, convention table, and review copy starts here. Note: its first table test (June 2026 — the overview's Stage 2 listing is stale) confirmed the core action teaches itself but **refuted the chaining tension** — everyone chained whenever possible, no bridge-burning decision surfaced. It needs a second test probing whether the Inferno variant (chain 3) or refusal pressure restores the decision, plus the untested announce rule. Not a flagship (too slight to carry a pitch) but the Core Set's front door and the recommended first game in your own learning order.

### Proposed Core Set slate (G3)

| Slot | Game | Status gap to close |
|---|---|---|
| Opener / party | WILDFIRE | second test: chaining tension (refuted in test 1), announce rule |
| Flagship / trick-taking | BLIGHT (+ GLEAN variant) | 4P/6P test, full-match test, blind test; GLEAN majority scoring untested |
| Depth / tactical | TRIGON *(conditional)* | handling re-test at 2P |
| 2P duel | CROSSROADS *(on notice)* or FACE VALUE | pass-to-win verdict decides |
| Solo | CAIRN (tray-sized, sim-validated) | first table test |
| Solo/co-op puzzle | TWELVE TRIALS or THE ORRERY | flip-tracking method (F12), then pick one |

Supporting cast (PNP extras / expansion / stretch goals): the non-selected puzzle sibling, TURNCOAT (expansion-natural: same engine as TRIGON), RELAY, FORKED TONGUE, THE COUNCIL, FACE VALUE if not slotted. Parked pending deck physics: JANUS, SLEEPER. Parked: THE UNPLAYED PAIR, SNARE.

## 4. Path decision: publisher vs self-publish

Recommendation: **build to pitch-ready, pitch publishers first, keep Kickstarter as the evidence-based fallback.** The fork decision lands around month 6–9, after blind-test results.

Why publisher-first fits *this* project: budget (£500–3k funds a pitch campaign — it does not fund the ~£10–25k of art, offset deposit, and fulfilment a credible KS needs); time (5–10 hrs/wk cannot run a crowdfunding campaign's marketing cadence alongside development); product risk (the deck's novelty needs a partner who solves retail positioning — novel systems are exactly what small-box specialist publishers exist for). The royalty maths (4–6% of wholesale, most games <5,000 copies/yr) means this is a portfolio play either way — which favours the path that costs you least.

Target publisher profile: small-box, mechanism-forward, low component count. Shortlist to research via Cardboard Edison (~$2/month — subscribe): **Button Shy** (18-card wallets — the 15-card subset fits), **Allplay**, **Oink Games**, **Helvetiq**, **Cheapass/Greater Than Games lineage**, plus UK Games Expo publisher-speed-dating. What they'll see: functional prototype, mood board, clear component list, no finished art, no rigid price — exactly what the course says to bring.

Kickstarter trigger conditions (revisit month 6–9): publisher route produces silence *and* blind tests show strong unsolicited enthusiasm *and* a PNP following exists (mailing list from contest entries). Then the plan changes shape — but not before.

## 5. Workstream actions

### 5a. Blind / external playtesting

Currently zero external sessions; everything so far is Sam-at-the-table. Escalate through four rings, cheapest first:

1. **Local, Sam-absent** — hand the PNP deck + rulebook to Lauren/Arran (or colleagues) and *leave the room*. Costs nothing, catches the worst rulebook failures before strangers see them. BLIGHT first (its rules already read clean).
2. **Digital tabletop** — build the deck once on **Screentop.gg** (free, card games are its sweet spot; the HTML reference tool's assets can seed it). Unlocks remote testers and makes ring 3 far more responsive.
3. **Structured stranger testing** — BGG Work-In-Progress forum thread per Core Set game; **Break My Game** Discord; **Playtest UK** if UK trips align (and UK Games Expo's playtest zone, June 2027 as the natural deadline).
4. **PNP contests** — the repo is unusually well-armed here: BGG's annual **Solitaire PNP contest** (CAIRN is tray-sized and sim-validated — near-ready), the **2-Player PNP contest** (FACE VALUE or CROSSROADS), Button Shy's design contests (15-card subset). Contests deliver blind testers, a public dated record (the pragmatic novelty stake, §1), and community visibility at £0.

Instrument every ring: a one-page feedback form derived from Templates/Playtest Report (first-read confusions, teach time, would-play-again, which game they'd buy). Blind-test the *Deck Handbook* alongside the game — F1/F9 handling guidance is part of what's being tested.

### 5b. Rulebook production

- **Adopt the two-document approach per game**: a teach-flow rulebook (game flow before edge cases) + a half-page quick reference. TRIGON's test proves the need — the answers existed but couldn't be found mid-turn. TRIGON specifically needs a **player-aid card**: all 9 symbol abilities on one sheet, one per player.
- **One shared Deck Handbook** (G1): the 9 signs and their ranks, dealing convention (F3), pile conventions (C3/F9), flip-tally method (F12), the "sign is rank" teach script (F4). Written once, referenced by every game — this is also what makes the collection *feel* like a system.
- **Structure for translation-readiness, don't translate**: numbered rules, short declarative sentences, icon-forward layout (symbol icons inline instead of sign names where possible), a single glossary, no idioms. Cheap now, expensive to retrofit.
- **Editing**: one professional rules-editing pass on the flagship only (~£150–300 of the budget), *after* blind testing stabilises the text. Everything else gets peer review (BGG WIP, Break My Game are good at this).
- Enforce the existing rulebook-standards ban on "face-down" language (F11) — it hides real mechanism gaps, and blind testers on a backless deck will find every instance.

### 5c. Art direction

The organising principle: **the deck is illustrated once; games are skinned in the rulebook, never on the cards.** Cards are shared by every game, so card faces must be game-neutral: sign icon, colour, numeral pip (top-left per F2), orientation marker — nothing else. Game identity (name, mood, cover art, rulebook accents) lives entirely in the rules booklet and box.

Priorities in order: (1) **commission professional icon/graphic design for the 9 signs** — the one art investment worth making now (~£300–800 for a 9-icon system + card face layout). Brief requirements straight from the findings: nine icons distinguishable at fan-scan speed (F1), rank ordinality visually encoded so Crown *reads* stronger than Moon (F4), colourblind-safe (9 hues alone won't be — icons must carry the load), legible rotated 90° (orientation-as-state games) and across a table (grid games). (2) Run the existing symbol_recognisability_test.html protocol on the commissioned set before accepting delivery. (3) A simple wordmark for the collection. Explicitly deferred: illustration, box art, themed skins — publisher territory, or post-fork if self-publishing. Course rule: no AI art in anything commercial; prototype-only.

### 5d. Production & cost realism

The component story is a genuine competitive asset: **36 cards, a rules booklet, possibly one bag/cover (T1), tuckbox or small two-piece box.** Nothing else.

| Path | Use | Realistic numbers |
|---|---|---|
| Home print (current) | design iteration | as now |
| **POD (Game Crafter / MakePlayingCards)** | blind-test copies, contest prizes, publisher prototypes | ~£8–15/copy; order 5–10 over the year (budget line ~£150) |
| **Offset (LongPack / Panda / LudoFact)** | only after the fork, if self-publishing | 36-card deck + booklet + small box ~$2.50–4/unit at 1–2k copies → ×5 gives $12–20; with freight unfactored the course's ×7–8 applies → target **MSRP $19–25 / £15–20**; file-to-warehouse 5–9 months |

One production risk is unique to this product and worth flagging in every manufacturer conversation: **there is no card back to hide misregistration.** Both faces are functional, so front-to-back print alignment tolerance — a cosmetic issue on normal decks — is a play-integrity issue here (a misaligned orientation marker or corner pip corrupts state-tracking). Ask POD and offset suppliers for their duplex registration tolerance and check it on the white/physical proofs. Similarly, edge wear and any face-identifying print defect matters double on a deck with no back. Action now: get a Game Crafter quote this month (free to spec), one indicative LongPack email quote at month ~4 — not to buy, but so the pitch sheet's cost estimate is real.

### 5e. Positioning & market comparables

The survey already establishes the structural white space (no published pure C(N,2) one-symbol-per-face deck; nearest: a 1986 patent, Ingenious, 2 Way Cards). Positioning must *not* lead with the maths. Consumer-language one-liner to iterate on:

> *"One deck of 36 two-faced cards — every card is two signs, and every possible pairing exists exactly once. Flip a card and it becomes something else. [N] games inside, 10–25 minutes each."*

Comparables to cite in a pitch (know them cold): **Ingenious** (every-pair elegance, mass appeal), **2 Way Cards** (double-sided orientation play), **The Decktet / Pairs** (one-deck game systems — and the honest lesson that systems undersell without a lead game), **Palm Island** (card-manipulation-as-mechanism selling a novelty deck), Button Shy's catalogue (proof small card counts sustain real games). Differentiator to hammer: the deck is a *closed, fully balanced system* — every pairing exists exactly once, so deduction, fairness, and "the deck is the board" all come free. Distinguish from Dobble early — everyone will reach for it, and it's a different structure.

### 5f. Pitch materials (build at day 60–90, not before)

One **pitch sheet per flagship** (one page: overview, big three stats, component list "36 double-faced cards + booklet", USP) plus one **system sheet** (the deck, the Core Set table, "13 further designs in development"). Elevator pitch must survive the telephone-game test. A 60-second phone-shot demo video of BLIGHT's slough moment and a WILDFIRE chain — table footage, no production values. That's the entire pitch kit; anything more is premature until a publisher bites.

## 6. Audience recommendation

**Hobby-first.** The games are light-to-medium hobby weight (trick-taking with memory inversion, tactical grids, combinatorial solitaire — not mass-market party fare); the all-pairs hook lands hardest with people who notice structure; every zero-cost channel available at this budget (BGG, contests, PNP community, small-box publishers) is hobby infrastructure. The gift/mass market is real for this product *eventually* — "one deck, many games" is a natural gift — but it's reached through a publisher's retail machine, not directly. Position hobby now; keep the system story clean enough that a publisher can see the mass-market angle themselves.

## 7. 90-day punch list (5–10 hrs/week ≈ one table session + one desk block per week)

Ordering principle: **validation before polish** — nothing in the first month spends money or polishes anything a table result could still overturn.

### Month 1 — close the loops that decide the flagships
1. **BLIGHT session: 4P (9-card hands) + start a full match** — answers hand-handling comfort and luck-washout, its two promotion blockers. *(table)*
2. **CROSSROADS verdict session: 2P, Signal Fires actually used, pass-to-win attempted deliberately** — this decides whether it keeps the 2P Core Set slot or FACE VALUE gets it. One session, binary outcome. *(table)*
3. **TRIGON handling fix on paper**: centre-first grid rule + draft the 9-ability player-aid card. *(desk)*
4. **WILDFIRE second table test** — 10 minutes as a warm-up before session 1 or 2, specifically probing the refuted chaining tension (try Inferno / chain 3) and the announce rule. *(table, free)*
5. **Settle DECK_CONVENTIONS tensions T1 and T3** provisionally (recommend: bag for T1 — cheap, solves F7 and F10 in one object; counters for T3 per F12) so the Deck Handbook can be drafted. *(desk)*
6. Get a **Game Crafter quote** for the 36-card deck + tuckbox. *(desk, 1 hr)*

### Month 2 — first external exposure
7. **TRIGON re-test at 2P** with grid fix + player aid → **flagship-2 decision gate**: promote, or demote to expansion tier. *(table)*
8. **Draft the Deck Handbook** (one page) + bring BLIGHT's rulebook to blind-readable (apply F4 teach script, F11 sweep). *(desk)*
9. **Ring-1 blind test**: BLIGHT + Handbook, Sam out of the room. Iterate the text on what breaks. *(table-adjacent)*
10. **Build the deck on Screentop.gg.** *(desk, one evening)*
11. **CAIRN first table test** (solo — do it any week) → if it lands, earmark for the next BGG Solitaire PNP contest. *(solo)*
12. **Commission the 9-sign icon system** — brief written from F1/F4/colourblind/rotation requirements; £300–800. This is deliberately *after* the flagship gates: the visual identity should launch with games that are staying. *(desk + spend)*

### Month 3 — strangers and paper
13. **BGG WIP threads** for BLIGHT and the winning 2P game; post PNP files; join **Break My Game** and run 2 remote sessions via Screentop. *(desk + evenings)*
14. **Enter one contest** with whichever is readiest (CAIRN solo / FACE VALUE 2P / a 15-card 6-symbol build for Button Shy). *(desk)*
15. **Icon delivery → recognisability test → regenerate PNP + POD order** of 3–5 blind-test copies. *(desk + ~£60)*
16. **Draft pitch sheets** (flagship + system) and the 60-second demo video. *(desk)*
17. **Declare the Core Set in COLLECTION_OVERVIEW.md** — the G3 decision, now evidence-backed. *(desk)*
18. **Day-90 review**: flagship states, blind-test signal, contest response → set the month-4–6 plan (publisher shortlist research via Cardboard Edison; UK Games Expo 2027 planning).

**Deliberately absent from these 90 days**: illustration beyond icons, box design, offset quotes beyond one email, Kickstarter prep, JANUS/SLEEPER work, new game concepts (the pipeline is rich enough — anti-drift rule: don't add content while flagship loops are unproven).
