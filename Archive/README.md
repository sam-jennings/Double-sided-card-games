# Archive

Files here are retained for their reasoning and history. They are **not current project guidance** and must not be used to infer a game's present status.

- `Audits/` — point-in-time collection and naming reviews. Some conclusions were later superseded.
- `Prompts/` — completed agent prompts kept as provenance.
- `Proposals/` — proposals that were never adopted as current standards, including two unadopted public-site designs (`index_singlepage_legacy.html`, the pre-split single-page picker; `index-redesign_singlepage_legacy.html`, an unwired paper-theme redesign). The live public site is `index.html` + `games.html` at the repository root.

Use [Collection Overview](../COLLECTION_OVERVIEW.md) for current game status and [Project files](../Project/README.md) for live cross-game guidance.
