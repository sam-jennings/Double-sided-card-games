## Prompt

I'm developing a board/card game project called the **Flip-Deck Collection**. Help me build a realistic, staged plan to take it from home-printed prototypes to a published product on shelves (retail or crowdfunded), acting as a game-development and publishing strategist. Use the project state below as ground truth, not generic advice.

### Project state

**Core system:** A double-sided card deck. Each card shows one symbol per side; every pair of the deck's symbols appears on exactly one card ("all-pairs" structure). Flipping a card is the core interaction — no hidden/face-down state.

**Deck decision (resolved June 2026):** 9 symbols, 36-card master deck. Any 6/7/8-symbol subset of the 36 is itself a valid smaller all-pairs deck, so individual games declare which symbol range they use rather than the collection being locked to one size.

**Collection status:**
- Complete and simulation-tuned: TRIGON, TURNCOAT
- In active development toward full rulebooks: JANUS, FORKED TONGUE, OUROBOROS
- Eight further concepts drafted but not yet built out (see NEW_GAME_CONCEPTS.md)
- Several other named prototypes in progress (Blight, Cairn, Crossroads, Face Value, Glean, Relay, Sleeper, The Council, The Orrery, The Unplayed Pair, Wildfire, Twelve Trials)

**What exists today:** rules drafts, deck-size/RTP-style balance analysis, playtest findings docs, symbol-set and naming conventions, a print-and-play folder, and an HTML reference tool. Everything is home-printed and unillustrated — no final art, no rulebook layout, no pitch materials, no cost/production analysis.

**Development framework I'm using** (for reference, so your plan should slot into it): Stage 0 Orientation → 1 Core Concept → 2 Fast Prototype → 3 Core Loop Validation → 4 Structural Iteration → 5 Content Expansion → 6 Usability/Communication → 7 Validation & Positioning → 8 Pitch/Publish Prep. The collection as a whole is roughly at Stage 5 (content expansion / core loop proven for at least two games), with individual games spread across stages 3-6.

### What I need from you

1. **A gap analysis**: given a collection (not a single game) with games at mixed maturity, what has to be true of the *whole collection* before any single game is pitch-ready — and what's genuinely optional?
2. **A sequencing plan**: which 1-2 games should be pushed to full "pitch-ready" first as flagship titles, and why — versus which should stay as a supporting cast (print-and-play extras, expansion content, stretch goals).
3. **Concrete next actions** across:
   - Blind/external playtesting (I've only run local sessions so far)
   - Rulebook production (structure, layout, editing, translation-readiness)
   - Art direction (symbol/theme identity across a 9-symbol shared deck used by multiple games — what's consistent vs. game-specific)
   - Production and cost realism (component list, MSRP target, manufacturer options, print-on-demand vs. offset run)
   - Positioning and market comparables (what existing games compete with an all-pairs flip-deck system)
   - Pitch materials vs. self-publish/crowdfund path — which fits this project better and why
4. **A prioritized punch list** (next 90 days) that doesn't over-invest in polish before the core loops across the flagship games are fully validated.

Ask me clarifying questions where you need them (e.g. target audience, budget, timeline, whether I want a publisher deal or to self-publish/Kickstart), but give me your best working plan with stated assumptions rather than waiting for perfect information.
